# Project contract

The input is UTF-8 JSON. Required fields: `title`, `angle`, `sources`, `scenes`.

## Channel handoff and preflight

New jobs for an ongoing channel can set `channel_dir` (relative to project.json or absolute) and the registered `topic_id`. The factory fills missing voice settings and AI-news visual preferences from that channel's profile; explicit project fields and `requirements` win. It records both input/effective project hashes and applied defaults. Projects without channel_dir retain legacy behavior. Pricing/audience choices still require editorial research; a profile does not verify prices.

Use `factory.py preflight --project <json> --stage draft|produce --output <json>` before expensive recording/TTS. It returns the effective settings, research age warnings and a scene-by-scene narration/material map. Draft preflight accepts declared future media paths and performs no synthesis. Production preflight checks actual files/recording lineage and rejects drafts awaiting approval. Readiness is technical, not editorial certification.

New projects add an `evidence_map` list. Each row uses `scene_id`, the scene's exact `source_ids`, exact used `media_ids`, `viewer_focus` and optionally `evidence_limit`. Example shape: `{"scene_id":"cost","source_ids":["domestic-price"],"media_ids":["rates-recording"],"viewer_focus":"对应型号、人民币单位和输入/输出费率","evidence_limit":"官网报价，非亲测总成本"}`. Replace these IDs with actual project IDs. An existing map with changed sources/shots fails preflight; the agent must review and update it. Legacy projects without a map get a warning, preserving compatibility. Python cannot decide if a picture proves a claim; inspect the returned map and encoded video.

Successful technical production linked to a topic writes actual artifact paths and `produced_pending_review`. It preserves published/cancelled states and never claims posting or editorial approval. Record the actual review and publication separately.

For current AI news use `content_type: ai_news` and `research_file` pointing to the completed research JSON, relative to project.json or absolute. See [AI news](ai-news.md). Production checks the dated searches, selected candidate, original-source claim checks and footage plan before generating audio/video, and includes research.json in the output.

For a model release set `story_type: model_launch` and add an `editorial_brief` in that research file, following [model-launch.md](model-launch.md). It records the audience decision, hook, capability/price evidence, competitor selection, meaningful limit and shot-to-claim mapping. Price tables preserve provider/version, check date, region, currency, unit and service conditions; graphics and narration should use the same values. Editorial judgment is reviewed by Codex rather than inferred from the presence of JSON fields.

This installation defaults to a Chinese audience: optional `audience_region: CN` and a `pricing_policy` note can record that choice. Research and media should prefer domestic Chinese pages and RMB prices for Chinese providers, while foreign providers retain official native prices. Document any currency conversion; do not derive cross-currency ratios from raw rates. A locale change also invalidates affected title/script/cover comparisons, even when the renderer's numeric schema still passes.

- `sources`: objects with unique `id`, `url`, `label`, `claims` (a list of verified factual statements), and optionally `published_at`, `capture_selector`. Cite original documents. Claim verification is performed by Codex; the renderer verifies references exist, not whether prose is true.
- `source.capture` defaults to true only for the legacy cards renderer. New shot modes already use declared media; source screenshots are acquired only when explicitly requested with `capture: true`, avoiding unused captures. News capture caches include the research record hash, so changed research does not silently reuse a previous price screenshot.
- Set `excerpt_only: true` on a GitHub source to capture a clearly labelled authentic source excerpt through the public contents API when direct page navigation is unavailable. A heading fragment such as `#privacy` selects that README section. The image metadata records its method and Git blob when available.
- `scenes`: 3–12 objects with `id`, `headline` (short, optionally newline-separated), `narration`, `body` (up to three short supporting lines), `source_ids` and `kind`. Kinds: `hook`, `evidence`, `steps`, `comparison`, `close`. Write/review the continuous script first, then divide complete ideas into these production fields; kinds do not prescribe spoken headings, rhetorical questions or a fixed narrative order. See [spoken news writing](spoken-news-writing.md). Keep the job's text review separate from automated preflight readiness.
- A scene may set `asset` to an existing local image, `asset_label` to explain it, `steps` to 2–5 short labels, `dark` to a boolean, and `accent` to a hex color. Missing screenshots get an explicitly designed factual text/diagram scene; the report records capture failures. A fallback never impersonates the source page.
- Optional `brand` (default `AI 工具观察`), `voice` (Edge/SAPI voice), `speech_rate` (Edge default `+8%`), `voice_mode` (`auto`, `edge`, `local`, `ming`), `voice_profile` (installed Ming `anime-c`), `voice_seed`, `voice_tempo` (pitch-preserving 0.8–1.2, Ming default 1.0), `music` (default true; procedurally composed locally), `cta`, `titles` (alternative publishing titles), `description`, `hashtags`, `selection_reason`, `candidate_file` and `width`/`height`/`fps` (default 1080/1920/24; only portrait 9:16 with width at least 360). An omitted voice_mode uses `.runtime/voice-default.json` when present, otherwise `auto`.

For new projects set `visual_mode`: `screencast`, `motion`, `montage` or `hybrid`. Read [the shot contract](shot-contract.md) for `media` and scene `shots`. The fields `asset`, `steps`, `dark` and `accent` above belong to the legacy `cards` renderer; they do not substitute for real shots. A missing `visual_mode` keeps old projects compatible with cards.

`visual_style: source_led` activates this installation's source-material coverage preset. Actual narration-based shot durations determine the source/recording ratios; distinct originals are grouped by `media.source_asset_id` or source URL/hash. See [source-led editing](recording-and-editing.md#source-led-news) for the configurable `requirements` fields. New-mode outputs include `visual-mix.json` with the measurements and shot-by-shot classification.

`approval_status` may be `draft`, `awaiting_user` or `approved`. Production is blocked for the first two states before any output/voice creation. An omitted state preserves direct-production workflows. This state records the user's actual requested stage; do not mark a draft approved just to make a command run.

Use source IDs on every externally factual scene. Do not place long news paragraphs on screen. An evidence scene should have a different headline, narration and visual role: headline states the point; narration explains; the actual screenshot or diagram supplies evidence.

Commands print stage-level JSON progress and write persistent state to the output folder. Final output includes `final.mp4`, `cover.png`, `captions.srt`, `publishing.md`, `sources.json`, `project.json`, `contact-sheet.jpg`, `report.json`, and reusable production assets under `assets/`. New modes also export `edit-plan.json` (actual timeline, source ranges, speed and camera parameters) and `media-manifest.json` (file hashes and declared rights).

On this configured host the user's default is local Ming with the selected C voice; read [local TTS](local-tts.md). Explicit auto mode first tries Edge TTS without a key, then on Windows falls back to an installed Chinese SAPI voice. Local mode explicitly uses SAPI and skips online speech. Ming mode uses the installed checkpoint and stops if it fails. If no suitable voice is available, fail rather than silently changing the speaker or language. The actual provider is in the report. Subtitle timing derived from scene audio is reported as proportional phrase timing; never claim forced alignment when it was not performed.

Automatic scene scores and topic scores are editorial heuristics. Keep stale-source and collection-failure information. This is a Codex workflow: the host agent provides reasoning and verifies claims. It is not an unattended standalone text model and does not reuse a Codex login token to call an API.
